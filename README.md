# 🌸 PinkStudy

Sesame's Study Space — a personal study scheduler.

## Features
- Pink-themed login
- Calendar with up to 3 study sessions/day
- Subjects: Data Analytics, Python Programming, Database Dev
- Study streak tracker & exam week countdown
- Quick notes per subject
- Stats with Chart.js (monthly + subject breakdown)
- Badges, confetti, and dark mode
- Saves data locally (localStorage)
